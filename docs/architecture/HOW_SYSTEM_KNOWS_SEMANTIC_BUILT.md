# How the System Knows If Semantic Indexing Is Built

**Answer:** By querying the PostgreSQL `analysis_artifacts` table for a specific record

---

## The Detection Mechanism

### Code: Line 307-315 in retriever.py

```python
def _load_semantic_index_from_artifact(self):
    """Load pre-built Chroma semantic index from analysis artifact."""
    
    # SQL Query: Check if semantic index artifact exists
    artifact = self.db.query(AnalysisArtifact).filter(
        AnalysisArtifact.analysis_id == self.analysis_id,  # Filter by analysis
        AnalysisArtifact.type == "semantic_index_db"       # Filter by type
    ).first()  # Get first match (0 or 1 record)
    
    # If record not found
    if not artifact:
        self.semantic_degradation = "artifact_not_found"
        logger.debug(f"No semantic_index_db artifact for analysis {self.analysis_id}")
        return []  # Semantic search disabled
    
    # If record found but has no data
    if not artifact.blob_data:
        self.semantic_degradation = "artifact_empty"
        logger.debug(f"semantic_index_db artifact is empty")
        return []
```

## Database Schema

### Table: `analysis_artifacts`

```sql
CREATE TABLE analysis_artifacts (
    id SERIAL PRIMARY KEY,
    analysis_id INTEGER NOT NULL REFERENCES analyses(id),
    type VARCHAR NOT NULL,          -- 'semantic_index_db' or 'bm25_index'
    data JSONB,                     -- Metadata (usually null for semantic)
    blob_data BYTEA,                -- Chroma index as zip file
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_analysis_artifacts_analysis_id_type 
ON analysis_artifacts(analysis_id, type);
```

## Verification: How to Check Yourself

### Check if Semantic Index Built

```python
from backend.database import SessionLocal
from backend.models.repository import AnalysisArtifact

db = SessionLocal()

# Query for semantic index artifact
artifact = db.query(AnalysisArtifact).filter(
    AnalysisArtifact.analysis_id == 123,
    AnalysisArtifact.type == "semantic_index_db"

if artifact:
    print(f"✅ Semantic index BUILT")
    print(f"   Size: {len(artifact.blob_data)} bytes")
    print(f"   Created: {artifact.created_at}")
else:
    print(f"❌ Semantic index NOT built")
```

## Why Database?

The system uses a **database query** instead of file checks because:

1. **Persistent** - Survives process restarts
2. **Transactional** - ACID guarantees
3. **Queryable** - Can filter by analysis_id
4. **Indexed** - Fast lookup (compound index)
5. **Shared** - Multiple processes can see same state
6. **Versioned** - Can track when built (created_at)

## Edge Cases

### Case 1: Semantic Started But Not Yet Finished
```sql
SELECT * FROM analysis_artifacts 
WHERE analysis_id = 123 AND type = 'semantic_index_db';
-- Result: 0 rows (thread still building)
-- System: Uses BM25 only, waits for next request
```

### Case 2: Semantic Built But Corrupted
```sql
SELECT blob_data FROM analysis_artifacts 
WHERE analysis_id = 123 AND type = 'semantic_index_db';
-- Result: NULL or corrupted data
-- System: artifact exists but blob_data is invalid
-- Exception caught: self.semantic_degradation = "load_failed"
-- Result: Falls back to BM25
```

### Case 3: Multiple Analyses (Different Repos)
```sql
SELECT * FROM analysis_artifacts 
WHERE type = 'semantic_index_db';
-- Result: Separate row for each analysis with its own artifact
-- Each analysis tracked independently
```

## Summary

| Question | Answer | How Known |
|----------|--------|-----------|
| Is semantic built? | Query DB for artifact | `db.query(...).first()` |
| Built for which analysis? | Filtered by `analysis_id` | WHERE clause |
| What type of artifact? | `type == "semantic_index_db"` | WHERE clause |
| Where's the data? | In `blob_data` column | BYTEA field |
| When was it built? | `created_at` timestamp | Database record |
| Is it corrupted? | Check `blob_data` not NULL | Exception handling |

**Bottom line:** The system queries the PostgreSQL database every time it needs to know if semantic indexing is available for an analysis. The database is the source of truth.
