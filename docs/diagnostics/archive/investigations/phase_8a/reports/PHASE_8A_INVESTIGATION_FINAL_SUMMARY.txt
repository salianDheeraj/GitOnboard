KEY LESSONS
================================================================================

1. VERIFY BEFORE TESTING
   - Phase 8A.6 assumed entities existed; Phase 8A.10 disproved this
   - Result: 3 phases of investigation on bad data
   - Prevention: Ground-truth verification FIRST

2. DIRECT EVIDENCE BEATS INFERENCE
   - Phase 8A.9 executed the parser directly; didn't argue about it
   - Result: Caught that parser works before implementation
   - Principle: Use actual code execution, not speculation

3. BAD TEST DATA IS WORSE THAN NO DATA
   - Phase 8A.6 produced a confident false conclusion (50% error rate)
   - Phase 8A.11 proved the real rate is 0% for verified symbols
   - Takeaway: Verify ground truth; bad assumptions cost time

4. PARALLELIZATION CATCHES PROBLEMS FAST
   - Three parallel agents (A, B, C) in Phase 8A.9 identified contradiction quickly
   - Result: Problem found in one turn; would have taken sequential sessions
